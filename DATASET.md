# Паспорт набора данных (DATASET.md)

## 1. Общие сведения
В работе используется географический и демографический набор данных из папки `DATASET`, состоящий из трёх связанных таблиц в формате CSV (кодировка UTF-8):
1. **`geonames.csv`** — глобальный реестр географических объектов GeoNames (объём: **1 404,47 МБ** / 1 472 693 307 байт, более 11 млн записей). Используется для формирования потокового отладочного среза на 200 000 строк и тестов производительности.
2. **`worldcities.csv`** — база крупных городов и населённых пунктов мира (объём: **5,09 МБ** / 5 335 278 байт, ~44 691 строка, разделитель `;`).
3. **`world_population.csv`** — демографический справочник стран мира с динамикой населения за 1970–2022 гг. (объём: **28,56 КБ** / 29 247 байт, 234 строки, разделитель `;`).

## 2. Описание столбцов основной таблицы (`worldcities.csv`)
| Столбец | Смысл | Исходный тип | Целевой тип | Пригодность для анализа |
| :--- | :--- | :--- | :--- | :--- |
| `city` | Название города | `object` (строка) | `string` | Да |
| `city_ascii` | Название города в ASCII | `object` (строка) | `string` | Да |
| `lat` | Географическая широта (-90..90) | `float64` | `float32` | Да |
| `lng` | Географическая долгота (-180..180) | `float64` | `float32` | Да |
| `country` | Наименование страны | `object` | `category` | Да (выносится в справочник 3НФ) |
| `iso2` | Двухбуквенный код страны ISO | `object` | `category` | Да |
| `iso3` | Трёхбуквенный код страны ISO | `object` | `category` | Да (внешний ключ для связи с `world_population.csv`) |
| `admin_name` | Административный регион / область | `object` | `string` | Да (есть пропуски) |
| `capital` | Статус столицы (`primary`, `admin`, `minor`, пусто) | `object` | `category` | Да (требуется заполнение пустых значений) |
| `population` | Численность населения города | `float64` | `float32` | Да (содержит пропуски и выбросы-мегаполисы) |
| `id` | Уникальный идентификатор города | `int64` | `int64` | Да (первичный ключ) |

## 3. Описание ключевых столбцов справочника (`world_population.csv`)
| Столбец | Смысл | Исходный тип | Целевой тип | Пригодность для анализа |
| :--- | :--- | :--- | :--- | :--- |
| `Rank` | Место страны по населению | `int64` | `int16` | Да |
| `CCA3` | Трёхбуквенный код страны (ключ соединения с `iso3`) | `object` | `category` | Да (первичный ключ справочника стран) |
| `Country/Territory` | Название страны или территории | `object` | `string` | Дублирует `country` из `worldcities` |
| `Capital` | Столица государства | `object` | `string` | Да |
| `Continent` | Континент | `object` | `category` | Да (выносится в справочник `continents` 3НФ) |
| `2022 Population` .. `1970 Population` | Численность населения по годам | `int64` | `int64` | Да |
| `Area (km²)` | Площадь страны в кв. км | `int64` | `int32` | Да |
| `Density (per km²)` | Плотность населения | `float64` | `float32` | Да |
| `Growth Rate` | Темп прироста населения | `float64` | `float32` | Да |
| `World Population Percentage` | Доля в мировом населении (%) | `float64` | `float32` | Да |

## 4. Обнаруженные дефекты данных (План очистки)
1. **Разделитель `;` и кавычки** в `worldcities.csv` и `world_population.csv`.
2. **Несогласованные имена столбцов** (пробелы, заглавные буквы, спецсимволы `Area (km²)`).
3. **Пропуски в `capital`, `admin_name`, `iso2` и `population`** (например, у Намибии код `NA` воспринимается парсером как `NaN`, а у обычных городов поле `capital` пустое).
4. **Неоптимальные типы данных** (`float64` для координат, `object` для повторяющихся стран и континентов).
5. **Экстремальные значения (выбросы) в `population`** (агломерации свыше 20–39 млн человек, такие как Токио и Джакарта).
